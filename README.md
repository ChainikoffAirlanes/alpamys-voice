# Твой голос — Alpamys

Небольшой мобильный веб-сервис, через который ученики могут анонимно или с именем отправить идею, проблему или предложение команде проекта в Telegram.

## Что внутри

- Next.js 16, React 19 и TypeScript;
- Tailwind CSS 4 и Lucide React;
- серверный маршрут `POST /api/submit`;
- безопасная отправка через Telegram Bot API: токен не попадает в браузер;
- серверная валидация, honeypot и лимит 3 сообщения за 10 минут с одного IP;
- демо-режим без Telegram;
- генератор качественного QR-кода и страница `/qr`.

## 1. Установка Node.js

Установите актуальную LTS-версию Node.js с [nodejs.org](https://nodejs.org/). Проверьте установку:

```bash
node --version
npm --version
```

## 2. Установка проекта

В папке проекта выполните:

```bash
npm install
```

### Самый простой запуск в Windows

Дважды щёлкните [START.bat](./START.bat). Скрипт сам:

1. установит зависимости, если это первый запуск;
2. найдёт IP компьютера в локальной сети;
3. создаст или обновит `.env.local`;
4. пересоздаст QR-код на локальный адрес;
5. запустит сайт и откроет его в браузере.

Не закрывайте открывшееся окно, пока пользуетесь сайтом. Для остановки нажмите `Ctrl+C`. Телефон и компьютер должны быть подключены к одной сети. Если Windows спросит разрешение для Node.js, разрешите доступ только для частных сетей.

## 3. Настройка переменных

Создайте `.env.local` рядом с `package.json` по примеру `.env.example`:

```env
DEMO_MODE=true
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
PUBLIC_SITE_URL=http://localhost:3000
```

Файлы `.env` и `.env.local` исключены из Git. Не вставляйте токен в код и не называйте переменную с префиксом `NEXT_PUBLIC_`.

## 4. Как создать Telegram-бота

### Быстрая настройка в Windows

1. Создайте бота через BotFather по шагам ниже.
2. Дважды щёлкните `SETUP_TELEGRAM.bat`.
3. Вставьте токен. Мастер проверит бота и откроет его чат.
4. Нажмите **Start**, отправьте боту любое сообщение и вернитесь в окно мастера.
5. Мастер сам определит `TELEGRAM_CHAT_ID`, запишет настройки в `.env.local`, отключит демо-режим и отправит тестовое сообщение.

После этого перезапустите сайт через `START.bat`.

1. Откройте в Telegram официальный аккаунт **@BotFather**.
2. Отправьте команду `/newbot`.
3. Укажите отображаемое имя и уникальное имя, заканчивающееся на `bot`.
4. BotFather пришлёт токен вида `123456:ABCDEF`. Это значение `TELEGRAM_BOT_TOKEN`.
5. Добавьте бота в нужную группу или откройте с ним личный чат и отправьте любое сообщение.

### Как узнать TELEGRAM_CHAT_ID

После того как бот получил сообщение, временно откройте в браузере:

```text
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```

В ответе найдите `message.chat.id`. Для группы значение часто отрицательное. Запишите его как `TELEGRAM_CHAT_ID`. Не публикуйте URL с токеном и не добавляйте его в историю Git.

Для настоящей отправки настройте `.env.local`:

```env
DEMO_MODE=false
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id
PUBLIC_SITE_URL=https://ваш-домен.example
```

## 5. Запуск и проверка формы

Для безопасной локальной проверки оставьте `DEMO_MODE=true` и запустите:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000), заполните форму и отправьте её. Появится экран успеха, а очищенные данные будут выведены только в терминал разработки. Затем переключите `DEMO_MODE=false`, заполните данные Telegram и повторите отправку — сообщение должно прийти в выбранный чат.

Если Telegram не настроен и демо-режим выключен, сайт продолжит работать, а форма покажет понятную ошибку настройки.

## 6. Создание QR-кода

Укажите итоговый адрес в `PUBLIC_SITE_URL` и выполните:

```bash
npm run qr
```

Файл будет создан в `public/qr.png`. Предпросмотр и скачивание доступны по адресу `/qr`. Перед печатью плакатов обязательно пересоздайте QR с боевым доменом.

## 7. Проверки и production-сборка

```bash
npm run lint
npm run typecheck
npm run build
npm start
```

После `npm start` production-версия доступна на `http://localhost:3000`.

## 8. Деплой на Vercel

1. Загрузите проект в закрытый Git-репозиторий GitHub/GitLab/Bitbucket.
2. В Vercel нажмите **Add New → Project**, импортируйте репозиторий и оставьте Framework Preset `Next.js`.
3. В **Settings → Environment Variables** добавьте:
   - `DEMO_MODE=false`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `PUBLIC_SITE_URL=https://ваш-домен`
4. Запустите Deploy.
5. После появления итогового домена обновите `PUBLIC_SITE_URL`, локально выполните `npm run qr`, закоммитьте новый `public/qr.png` и разверните проект повторно.

Встроенный rate limit хранится в памяти процесса. Для небольшого MVP этого достаточно; при заметной нагрузке или нескольких serverless-инстансах его стоит заменить на Redis/Upstash.

## Структура

```text
app/                 страницы и API
components/          интерфейсные компоненты
lib/                 валидация, модерация, rate limit, Telegram
scripts/             генерация QR-кода
public/              логотип-placeholder и QR
```

`public/logo.svg` — аккуратный placeholder. Его можно заменить фирменным логотипом, сохранив путь или обновив компонент `components/Logo.tsx`.
